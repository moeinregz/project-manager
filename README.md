# پروژه‌هام — مدیریت پروژه‌ها

یه برنامه‌ی کوچیک و جدا برای مدیریت پروژه‌های طراحی سایت، سئو و نرم‌افزار. اطلاعات توی یه فایل SQLite ذخیره می‌شه (`projects.db`).

فایل‌ها:

| فایل | کارش |
|---|---|
| `app.py` | خود برنامه |
| `passenger_wsgi.py` | برای اجرا روی هاست cPanel یا PythonAnywhere. **رمز ورود اینجا تنظیم می‌شه.** |
| `api/index.py`، `vercel.json` | برای اجرا روی Vercel |
| `start-windows.bat` / `start-mac-linux.sh` | اجرای سریع روی کامپیوتر خودت |

---

## ۱) اجرا روی کامپیوتر خودت

فقط **پایتون ۳.۸ یا جدیدتر** لازمه (از python.org؛ تو ویندوز تیک «Add Python to PATH» رو بزن).

- **ویندوز:** روی `start-windows.bat` دوبار کلیک کن.
- **مک / لینوکس:** `python3 app.py`

مرورگر خودش باز می‌شه روی `http://127.0.0.1:8765`. این حالت رمز نداره چون فقط روی همون کامپیوتر باز می‌شه.

---

## ۲) آنلاین کردن (باز کردن از هر جا، با گوشی و لپ‌تاپ)

یه هاستی لازمه که **پایتون** ساپورت کنه و **فایل‌ها رو نگه داره** (چون دیتابیس یه فایله). روی Vercel هم می‌شه (راه ۱)؛ اونجا فایل دیتابیس توی Vercel Blob نگه داشته می‌شه.

برنامه موقع آنلاین بودن:
- **رمز ورود** می‌خواد (بدون رمز اصلاً اجرا نمی‌شه)
- به گوگل می‌گه **ایندکسش نکنه**، پس تو نتایج جستجو نمیاد و اطلاعاتت خصوصی می‌مونه

### راه ۱: Vercel (رایگان)

دیتابیس همون یه فایل SQLite هست (`projects.db`). Vercel بعد از هر درخواست فایل‌ها رو پاک می‌کنه، برای همین برنامه این فایل رو توی **Vercel Blob** نگه می‌داره. Vercel Blob فضای ذخیره‌ی فایل خود Vercel هست و هر بار که چیزی ثبت می‌کنی، فایل اونجا ذخیره می‌شه.

۱. توی Vercel بزن **Add New → Project** و ریپوی `project-manager` رو **Import** کن.
   - **Framework Preset:** `Other`. بقیه‌ی تنظیمات Build رو دست نزن.
   - توی **Environment Variables** یه متغیر بذار:
     - Name: `PM_PASSWORD`
     - Value: رمز ورودت (حداقل ۸ کاراکتر)
   - بزن **Deploy**.
۲. توی همون پروژه برو تب **Storage** ← **Create Database** (یا Create) ← **Blob** ← یه اسم بده ← **Create**. اگه پرسید به کدوم پروژه وصل بشه، همین پروژه رو انتخاب کن (**Connect**). این کار متغیر `BLOB_READ_WRITE_TOKEN` رو خودش می‌سازه.
۳. برو تب **Deployments**، روی آخرین Deploy سه‌نقطه رو بزن و **Redeploy** کن.
۴. آدرسی که Vercel می‌ده رو باز کن، رمز رو بزن و تمومه. ✔

> اگه رمز یا Blob رو تنظیم نکرده باشی، برنامه یه پیام نشون می‌ده که دقیقاً چی کمه.
> اگه بعداً رمز رو عوض کردی، دوباره **Redeploy** کن.
> **انتقال اطلاعات قبلی:** اگه روی کامپیوترت پروژه ثبت کردی، از تب Storage ← Blob ← Upload، فایل `projects.db` خودت رو توی پوشه‌ی `project-manager/` آپلود کن، به اسمی که با `project-manager/projects` شروع بشه. برنامه همیشه جدیدترین فایل اون پوشه رو برمی‌داره.

### راه ۲: هاست ایرانی cPanel که «Setup Python App» داره

بیشتر هاست‌های لینوکسی ایرانی این گزینه رو دارن. قبل از خرید از پشتیبانی بپرس: «هاستتون Setup Python App داره؟»

۱. توی cPanel برو به **Setup Python App** و بزن **Create Application**:
   - **Python version:** ۳.۸ یا بالاتر
   - **Application root:** `projects` (یه پوشه‌ی جدید، **نه** داخل `public_html`)
   - **Application URL:** دامنه یا ساب‌دامنه‌ای که می‌خوای، مثلاً `pm.yourdomain.com`
   - **Application startup file:** `passenger_wsgi.py`
   - **Application Entry point:** `application`
   - بزن **Create**.

۲. توی **File Manager** برو داخل پوشه‌ی `projects`. فایل zip رو آپلود کن، Extract کن و فایل‌های داخل پوشه‌ی `project-manager` رو بیار بیرون، توی خود `projects`. اگه پرسید `passenger_wsgi.py` جایگزین بشه، بزن بله.

۳. فایل `passenger_wsgi.py` رو با **Edit** باز کن و این خط رو عوض کن:
   ```python
   PASSWORD = "CHANGE-ME"
   ```
   مثلاً بکنش `PASSWORD = "یه-رمز-قوی-و-طولانی"` (حداقل ۸ کاراکتر) و ذخیره کن.

۴. برگرد به **Setup Python App** و بزن **Restart**.

۵. برای اون دامنه **SSL** رو فعال کن تا آدرس `https` باشه. معمولاً از بخش **SSL/TLS Status** یا **Let's Encrypt** توی cPanel انجام می‌شه.

۶. آدرس رو باز کن، رمز رو بزن و تمومه. ✔

> اگه قبلاً روی کامپیوترت پروژه ثبت کردی، فایل `projects.db` خودت رو هم توی پوشه‌ی `projects` آپلود کن تا همه‌ی اطلاعاتت بیاد.

### راه ۳: PythonAnywhere (رایگان، خارجی)

پلن رایگانش کافیه. آدرست می‌شه `USERNAME.pythonanywhere.com`. (ممکنه از ایران برای ثبت‌نام VPN لازم بشه.)

۱. ثبت‌نام کن (Beginner account).
۲. از تب **Files** یه پوشه بساز به اسم `projects` و `app.py` و `passenger_wsgi.py` رو داخلش آپلود کن.
۳. همون‌جا `passenger_wsgi.py` رو باز کن و `PASSWORD` رو عوض کن (مثل مرحله‌ی ۳ بالا).
۴. برو تب **Web** ← **Add a new web app** ← **Manual configuration** ← جدیدترین نسخه‌ی پایتون.
۵. توی همون صفحه روی لینک **WSGI configuration file** بزن، **همه‌ی** محتواش رو پاک کن و این سه خط رو بذار (`USERNAME` رو با اسم کاربری خودت عوض کن):
   ```python
   import sys
   sys.path.insert(0, "/home/USERNAME/projects")
   from passenger_wsgi import application
   ```
۶. ذخیره کن. توی تب **Web** گزینه‌ی **Force HTTPS** رو روشن کن و بزن **Reload**.
۷. `USERNAME.pythonanywhere.com` رو باز کن. ✔

> تو پلن رایگان، باید هر ۳ ماه یه بار توی تب Web دکمه‌ی «Run until 3 months from today» رو بزنی.

### بعد از آنلاین شدن

- **بکاپ:** هر چند وقت یه بار دکمه‌ی «بکاپ» بالای صفحه رو بزن و فایل رو یه جای امن نگه دار.
- **عوض کردن رمز:** `PASSWORD` رو توی `passenger_wsgi.py` عوض کن و برنامه رو Restart/Reload کن. همه‌ی دستگاه‌ها از حساب خارج می‌شن.
- **خروج:** دکمه‌ی خروج کنار «پروژه‌ی جدید». بعد از ورود، هر دستگاه ۳۰ روز وارد می‌مونه.
- اگه ۸ بار پشت سر هم رمز اشتباه زده بشه، ورود از اون اینترنت ۱۵ دقیقه بسته می‌شه.

## امکانات

- ثبت پروژه با نوع (طراحی سایت / سئو / نرم‌افزار / سایر)، مشتری، مبلغ قرارداد، تاریخ شروع و ددلاین
- مراحل آماده برای هر نوع پروژه (قابل ویرایش، جابه‌جایی، حذف و اضافه) و نمایش اینکه الان مرحله‌ی چندمی
- «کار بعدی که باید انجام بدم» و «کارهایی که انجام دادم» (با تاریخ و ساعت)
- پول‌های دریافتی، هزینه‌ها، خلاصه‌ی مالی هر پروژه و کل، و نمودار درآمد ۶ ماه اخیر
- فیلتر و جستجو، تم تیره و روشن، کار روی موبایل
- میانبر: `N` پروژه‌ی جدید، `/` جستجو

## تنظیمات اختیاری (متغیر محیطی)

- `PM_PASSWORD` رمز ورود (روی هاست؛ جایگزین خط توی `passenger_wsgi.py`)
- `BLOB_READ_WRITE_TOKEN` روی Vercel، وقتی Blob رو وصل کنی خودش ساخته می‌شه
- `PM_PORT=8800` پورت دیگه برای اجرای محلی
- `PM_HOST=0.0.0.0` باز کردن از گوشی تو همون وای‌فای. **با این گزینه حتماً `PM_PASSWORD` هم بذار.**
- `PM_DB` مسیر فایل دیتابیس
